# cloth-constraint-solver

## 题面

给角色加布料解算后，披风不是穿模就是抖成弹簧：积分用显式欧拉，刚度一大就发散；约束迭代不按 stiffness 加权，布面软得像橡胶；约束顺序固定、自上而下求解，下摆越拉越长；碰撞只推速度不推位置，高速时直接穿模；钉住的点求解后不回位，整块布缓慢漂移；拉伸比不设上限，极端帧把布料撕开；自碰撞忽略厚度，布片叠在一起就粘死；阻尼按帧数衰减，换帧率手感全变；批量模拟共用可变位置数组，多块布互相串扰；出现 NaN 只跳过该帧，后续帧继续拿 NaN 计算。cloth/solver.py 是核心，tests/test_solver.py 15个红。要修的是：半隐式欧拉与按时间常数衰减的阻尼、按 stiffness 加权且与约束顺序无关的 PBD 距离约束、位置级球/平面碰撞、钉点回位、拉伸比钳制、带厚度的自碰撞、批量模拟状态隔离与出现非有限值时的整体回滚。

## 运行方式

在本目录执行：

```bash
python -m pytest tests -q
```

初始状态必须恰好为 `15 failed`，且没有 collection/import/syntax error。15 个测试都会直接调用 `cloth/solver.py` 中的桩函数，所以当前全部失败是预期结果。

## 约束

- 只使用标准库 `math` 与 `pytest`；离线、无随机、无外部依赖。
- 固定时间步由调用方显式传入，不读取真实时钟，不做隐藏的帧率换算。
- 位置结果容差 `1e-6`，速度结果容差 `1e-6`；迭代次数全部显式传入。
- `tests/` 不可修改，修复应集中在 `cloth/solver.py`。
